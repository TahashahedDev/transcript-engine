# Security Policy

If you find a security vulnerability in Transcript Engine, please report it
privately rather than opening a public GitHub issue.

**How to report:** open a
[private security advisory](https://github.com/TahashahedDev/transcript-engine/security/advisories/new)
on this repository, or email the maintainer listed on the
[GitHub profile](https://github.com/TahashahedDev).

Please include:
- A description of the issue and its potential impact
- Steps to reproduce, or a minimal proof of concept
- The affected version/commit

**What to expect:** an acknowledgement as soon as reasonably possible, and a
fix or mitigation plan once the report is triaged. Please allow time to
address the issue privately before any public disclosure.

## Scope

This policy covers the code in this repository. Vulnerabilities in third-party
dependencies (PyTorch, FastAPI, Next.js, NVIDIA NeMo/Parakeet, pyannote.audio,
etc.) should be reported to those projects directly, though a report here that
identifies how this project is affected is also welcome.
